# OpenCV Image Analyzer

A computer vision web application built with Python, OpenCV and Flask.

## Features
- Image upload
- Face detection
- Eye detection
- Face and eye counting
- Browser-based results

## Technology
- Python
- OpenCV
- NumPy
- Flask
- HTML, CSS and JavaScript

## Project Structure

```text
opencv-image-analyzer/
├── api/
│   └── index.py
├── public/
│   └── index.html
├── .gitignore
├── README.md

```
